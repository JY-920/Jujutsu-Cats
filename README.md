# 咒术映界 · Jujutsu Realms

Minecraft 咒术猫咪与术式模组。当前 Java 版本为 **0.113.12**，模组 ID 为 `jujutsuvfx`。

| 工程 | 平台 | Java |
| --- | --- | --- |
| `forge-vfx/` | Minecraft 1.20.1 / Forge 47.4.20 起 | 17 |
| `neoforge-vfx/` | Minecraft 1.21.1 / NeoForge 21.1.248 | 21 |
| `netease-vfx/` | 网易基岩版 ModSDK 实验移植 | Python 2 兼容脚本 |
| `models/` | Blockbench 模型源文件，含末地传送门框架 | — |

Java 双端包含五条悟猫、宿傩猫、魔虚罗、乙骨忧太猫、夏油杰猫和里香猫协助，苍、赫、茈、解、捌、灶开、空间斩、咒言、极之番·漩涡、纯爱冲击波及领域，猫咪战斗演出、自动运镜、体术、三维咒具游云与乙骨的刀。网易工程仍是独立实验版本，不与 Java 功能完整等价。

## 当前版本更新

完整说明见 [0.102.5 至 0.113.12 更新记录](CHANGELOG.md)。本次汇总包含此前未推送的空间斩提交，以及乙骨、夏油、里香、舞蹈、对波与近期动作修复。

- 真赝相爱改为抽取两种不同术式并实际释放；取消早期固定的雅各布天梯打击。乙骨在自己的领域内获得 1.5 倍伤害；玩家展开该领域期间获得术式增幅，术式伤害提高 25%。
- 常规战斗中，五条、宿傩和乙骨在自身 50% 与 10% 血量阶段各有一次开域机会；实际参与定制演出的战斗由对应剧本管理。
- 夏油使用七种游云近战动作组成连招，并召唤咒灵、后撤与释放漩涡。乙骨对夏油拥有独立演出、术式特写和对波结尾。
- 玩家可使用咒言、真赝相爱、极之番·漩涡、纯爱冲击波、乙骨的刀及两种舞蹈道具。领域需长按完成结印；两种冲击波独立使用时持续释放，相遇后触发碰撞爆炸演出。
- 0.113.12 修正里香舞蹈手臂弯折处的尖片与网格翻折，保留已确认的拳头位置、动作角度与节奏。

下方标注旧版本号的章节是历史开发记录，其中的早期规则以本节和更新记录中的当前实现为准。

## 构建 Java 双端

在对应工程目录执行，提前将 `JAVA_HOME` 指向所需 JDK。

Forge：

```powershell
cd forge-vfx
.\gradlew.bat --no-daemon build
```

NeoForge：

```powershell
cd neoforge-vfx
.\gradlew.bat --no-daemon build "-PsableJar=C:/dependencies/sable-neoforge-1.21.1-2.0.3.jar"
```

NeoForge 编译需要外部 Sable 2.0.3 JAR，用于可选航空学物理兼容接口。通过 `sableJar` 指定本机路径；构建会提取其内嵌 companion API，但不会把物理引擎打包进本模组。游戏中未安装航空学时，捌使用普通方块破坏路径。

Linux/macOS 使用 `./gradlew`。产物在各工程的 `build/libs/`；`build` 同时运行已有自动检查。

## 配置

进入世界后按 **G** 打开配置。画面与配乐设置保存在客户端；方块破坏、演出模式、术式伤害和领域持续时间由服务器保存，修改需要管理员权限。

三个领域的常规持续时间可分别输入 **5–120 秒**；无量空处与伏魔御厨子默认 **5 秒**，真赝相爱默认 **20 秒**。新配置影响下一次常规释放；已展开的领域、领域对抗计时和演出固定桥段保持原定节奏。管理员指令可明确指定临时时长。

## 乙骨正式模型与领域强化（0.107.3）

接入用户提供的乙骨猫模型、64×32 猫皮肤与 64×64 细节贴图。头发、衣服和袖子保留原始网格及 UV，绑定现有猫骨骼、肘部与翻掌动作；保留背刀、抛刀叼刀、近战和独立结印。领域全部刀使用同一份用户提供的太刀贴图，修正 Minecraft 自动 Sampler0 上传覆盖贴图的问题，并减弱刀身紫色染色。

乙骨位于自己的已展开领域内时，近战、随机术式刀和天梯伤害乘以 1.5；玩家伤害先应用原有平衡再乘加成，仍遵守护甲、盾牌、队伍与 PVP 规则。蓄势、离开领域或领域结束不享受加成。取消领域内的咒言禁锢及术式刀定身，领域外仍保留咒言。身体包裹跟随实际动作轮廓的紫色流动辉光，通过实体数据同步给旁观玩家。

双端构建、领域规则、模型骨骼/UV/两材质回归与本机隐藏 OpenGL 领域材质检查通过。离线模型预览不是游戏截图；本版尚未游戏内或联机实测。联机双方应使用相同版本。

## 乙骨领域崩溃与独立结印修正（0.107.2）

修正领域渲染向浮点 Reveal、Opacity 参数调用整数 setter 导致的空指针崩溃。新增检查覆盖生产字节码的 uniform 写入类型，并直接调用 Minecraft 浮点 Uniform 缓冲写入；双端构建均通过。

领域展开不再复用五条／宿傩的结印：乙骨猫起身后左爪收于胸前、右爪掌面朝上前伸，保持结印后恢复。翻掌与肘部弯曲使用分离骨骼，保留肩部与尾巴连接及动作过渡。参考[乙骨手势资料](https://ciatr.jp/topics/324207)，猫模型以爪臂轮廓表达手势，没有独立手指。本版完成模型几何与动作回归检查，尚未进行游戏内实测。

## 生存玩家与半血领域修正（0.107.1）

乙骨、五条和宿傩在常规战斗中降至 50% 血量时展开领域，目标可以是主动招惹它们的生存玩家；保留原有 10% 血量阶段。五条与宿傩仅在实际参与双猫演出时由演出管理领域，单纯开启演出配置不会屏蔽对玩家的半血开域。乙骨先接近到目标 36 格内，再以目标位置为中心展开领域，避免远距离开空域。

玩家释放的苍、赫、各形态茈、开、解、捌、空间斩及领域均允许命中其他生存玩家，继续遵守服务器 PVP、队伍友伤及创造／旁观免疫。苍、赫、茈不再将骑乘状态当作伤害免疫；骑乘期间的载具运动仍由原版管理。苍牵引与赫击退显式同步到受击玩家客户端；本次没有提高既有玩家伤害。

## 乙骨领域「真赝相爱」（0.107.0）

乙骨猫在有敌对目标、血量降至 50% 和 10% 时各自动展开一次领域；存档记住已使用的血量阶段，回血不会刷新，死亡不会开域。先完成 1.5 秒结印，再展开半径 40 格的剑冢；默认持续 20 秒，可在 G → 领域持续时间中单独设置。当前由乙骨 AI 使用，没有新增玩家领域物品。

场景包含 144 把原始太刀模型、密集白色残破柱架、横贯上空的红白结绳、紫黑天空与淡紫雾气，靠独立 GLSL 材质及批量几何绘制，不生成装饰实体或修改地形。玩家进入范围才看到领域场景。每秒同步状态，后进入观察范围不会重播展开动画。

必中使用雅各布天梯：展开后先预留 1.5 秒，再每秒结算一次。普通敌人每次基础 24 点，玩家平衡基础 6 点（之后计算护甲等）；G → 术式伤害可调整天梯伤害。它只影响敌对目标、不要求视线、不破坏方块，离开领域可避开后续伤害。魔虚罗可适应该伤害来源。

乙骨会俯身拔取随机术式刀，一次成功近战消耗一次复制能力：咒言「别动」、空间碎裂打击或复制斩击。场内继续正常近战，主动位移限制在领域内。与已有无量空处或伏魔御厨子重叠时进行 5 秒对抗，期间暂停天梯必中并保护乙骨免受对方领域影响，随后随机胜方；落败领域提前消散。

包含专用展开、落光、拔刀音效及联机事件。Forge 总网络协议以及双端配置封包已升级，联机双方需同步更新。构建/规则/模型/封包回归和本机隐藏 OpenGL 材质检查通过；预览图是生产模型与着色器的离线渲染，不是游戏截图，尚未进行本版游戏内或联机实测。

视觉与规则参考：[真赝相爱设定整理](https://jujutsu-kaisen.fandom.com/wiki/Authentic_Mutual_Love)。伤害、时间与 AI 触发为本模组玩法设计。

## 乙骨咒言「别动」（0.106.0）

乙骨猫在中距离战斗中会短暂蓄势，释放前方 12 格锥形咒言，定住有视线的敌对目标并尝试衔接突进近战。玩家和普通生物基础定身均为 3 秒；同一目标有 4 秒重复控制保护，施法冷却 12–15 秒。魔虚罗的适应会缩短控制。蓄势阶段受击可打断；该技能本身不造成伤害，也不破坏方块。目前由乙骨 AI 使用，没有新增玩家物品。

特效包含嘴边紫白咒印、向前扩散的多层声浪、空气折射、目标符纹束缚、轻微镜头冲击及自制音效，沿用战斗事件广播同步给附近客户端。声浪使用 GLSL 150 材质，折射复用现有场景快照及渲染状态恢复。

双端构建包含范围、控制时长、连招窗口和声浪运动检查。`tools/verify_cursed_speech.py` 可用本地 LWJGL 和 OpenGL 隐藏窗口检查新着色器并导出材质预览；这不等于游戏内演出、联机或其他显卡实测。

乙骨的追击位移、拔刀冲刺和持刀突刺会在开启术式方块破坏时清除路径上的障碍，不产生掉落物；关闭配置时保留普通碰撞。路线预检不修改世界，真正位移时才按既有每刻预算清理，保留不可破坏方块、保护事件和脚下地面。

## 空间斩（0.102.7）

创造物品栏中的“空间斩”，或使用 `/give @s jujutsuvfx:world_cut` 获取。右键摆手后，以出刀时的视线贯穿前方 48 格路径上的多个生物，冷却 2 秒，可穿过地形；本技能不切割方块或物理结构。

服务端直接执行死亡流程，跳过普通伤害、护甲、盾牌、不死图腾，以及本模组猫咪的终结演出。保留队伍、创造/旁观模式和服务器 PvP 保护规则；术式伤害倍率不改变处决效果。末影龙使用原版即时死亡收尾，保留末地进度。

客户端采集命中时的模型顶点、姿势与贴图，按刀痕所在斜面裁切并封闭断面，再将两半弹开、碎散；约 0.8 秒消失。服务器广播给附近装有模组的观察者。Forge 联机双方需使用本版协议。

模型裁切支持标准 `NEW_ENTITY` 四边形渲染通道，包括原版生物、玩家和本模组猫咪；绕过该顶点通道的第三方自定义渲染器需要另行适配。几何裁切、顶点数据保留、路径判定和数据包往返有自动检查；这些检查不等于游戏内画面或联机实测。

### 0.102.7 空间斩演出修正

空间斩改为从玩家眼前飞出的亮白横斩，随机倾斜 ±12°；48 格行程、8 格刀宽，飞行中贯穿沿路生物。命中后模型沿斩面分开并加速爆散，附加白色碎屑与短促震屏。独立的向外甩臂动作和原创拔刀音效。刀痕使用主画面发光材质，避免原版闪电的天气缓冲区覆盖问题。客户端和服务器必须同步更新。


### 0.102.8 空间斩专用材质

刀宽和命中宽度扩大为 12 格。新增 `world_cut_blade` GLSL 材质：亮白尖锋、流动裂纹、柔光和沿飞行方向撕散的拖尾，直接绘制世界几何而非采样全屏画面。拔刀音重新合成为金属摩擦和破风，生成源码见 `neoforge-vfx/tools/generate_world_cut_audio.py`。


### 0.102.9 空间斩空气折射

刀宽与命中宽度扩大到 20 格；新增沿刀锋移动的空气折射压力波。每帧所有刀痕共享一次场景采样，深度遮挡约束避免拉扯前景，效果强度跟随游戏的画面效果强度设置。


### 0.103.0 空间斩破坏与第一人称动作

刀宽与命中宽度扩大至 30 格。管理员开启术式方块破坏后，空间斩沿飞行斩面切除方块，复用受保护区域检查与无掉落、限时分批队列；不可破坏方块不阻止刀光前进。第一人称改为肩端固定、手掌向外甩出的动作，第三人称动作保持原样。


## 0.104.0 乙骨忧太猫

- 通过创造物品栏的「乙骨忧太猫刷怪蛋」或 `/summon jujutsuvfx:yuta_cat` 生成。暂用原版白猫模型，体型与其他普通术士猫一致，800 生命。
- 使用提供的 reference_katana 模型及原贴图，缩放后全长约 1.73 格；平时背负，首次剩余血量不高于 75%（600 点）时扭身抛刀，空中旋转两圈、嘴部接刀，向前冲刺最多 5 格攻击。遇到实体碰撞方块会停下，不穿墙。
- 拔刀后持续叼刀，以横斩、反向斩、下劈轮换攻击；拔刀前爪击。拔刀状态存档保存，回血不重复演出。
- 默认演出配置开启时与宿傩互相敌对；关闭该配置后遵守现有中立规则。对玩家默认中立，受击会还手。乙骨不会套用五条的术式或新宿演出阶段。
- 服务器负责动作阶段、命中和位移，客户端同步同一段持刀动画。刀是生物渲染附件，不生成可复制或捡取的掉落刀实体。


## 0.104.1 乙骨外观修复

修正原版白猫贴图路径；背刀整体后移，按完整刀身（含刀柄）的边界避开头部转动范围。自定义网格移至 meshes 目录，避免被原版模型加载器误解析。


## 0.105.0 乙骨体术与剑术

- 第一阶段复用五条猫的直拳、勾拳、上勾拳、肘击、连打、旋转飞踢、双掌击与扫腿，左右手轮换。前腿增加肘关节，尾巴与躯干联动。
- 持刀阶段包含左右横斩、交叉二连斩、回旋斩、突进刺击、挑斩和劈斩，保留 75% 血量时抛刀叼刀与五格冲刺。
- 客户端按游戏刻推进动作并插值，延迟的动作帧不再令动画倒播；动作前后增加三刻过渡。普通命中加入两刻顿感，连打/二连斩分别结算命中。
- 双端共用动作逻辑和参数。验证包括稀疏/延迟同步、连续同招、模型矩阵连续性、刀与头部间距及抛刀落嘴连续性；尚未进行本版本的游戏内视觉验收。


## 0.105.1 乙骨位移与两倍近战速度

- 乙骨增加短距追击、侧闪、连招后撤与越障跃进，按距离、受击和连招状态选择；移动保留真实碰撞，起步前检查路线和落点。
- 体术与持刀近战的动作时间线、命中和收招同步两倍速，命中顿帧与攻击间隔减半（游戏刻取整）。抛刀叼刀的换阶段演出保持原速度。
- 服务端逐一处理跨过的动作帧，确保奇数帧命中、交叉二连斩、连续拳击不漏判。普通乙骨近战使用独立伤害来源避开受伤无敌帧吞刀，玩家减伤/盾牌仍走近战规则。
- 本版本不包含新术式，咒言/里香仅为下一阶段建议。

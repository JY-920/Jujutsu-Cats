# 咒术映界 · Jujutsu Realms（Forge 1.20.1）

此工程移植自 NeoForge 1.21.1 的当前 0.92.0 版本，使用相同的 `jujutsuvfx` 模组 ID。产物为 `build/libs/jujutsu-vfx-0.92.0-forge-1.20.1.jar`，需要 Forge 47.4.22 和 Java 17 或更新版本。

已移植苍、赫、茈（含 200% 与无限制）、灶·开、解、捌、两个领域及对抗、咒力缠拳和黑闪，以及五条猫、宿傩猫、魔虚猫的模型、动画、战斗 AI、适应、召唤和调试功能。保留当前所有贴图、着色器和音效。领域默认半径 40，G 键打开设置；破坏方块默认关闭，只有管理员可以修改。

联机的玩家与服务端均使用此 Forge 版本，术式、领域、姿势和命中效果通过独立的 Forge 网络通道同步。第一人称手臂使用 Minecraft 实际的光照纹理，避免读取被光影复用的纹理槽。

Forge 1.20.1 不加载 NeoForge 1.21.1 的 Sable 接口。“捌”采用普通方块切割并保留伤害、随机斩面和长按快速连斩；动态结构选项隐藏。当前版本不提供 Forge 1.20.1 的航空学或其他物理引擎适配。

源代码位于本工程 `src/main`。网络适配在 `platform`，1.20.1 顶点提交在 `RenderBuffers`，Mixin 的 SRG 映射由 Gradle 生成并写入最终 JAR。不要直接把 NeoForge JAR 放进 Forge 实例，也不要将两种版本同时装入同一个实例。

构建：在本目录使用 Java 17 执行 `./gradlew.bat assemble`。此命令编译并生成正式环境用的映射，不运行游戏或测试套件。最终包的静态校验记录位于 `build/release-092-package.json`；本次未进行游戏、专用服务器或联机运行测试。
